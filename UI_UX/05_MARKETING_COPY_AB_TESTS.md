## 4. A/B TEST STRATEGY

### Testing Philosophy

```
We test what matters:
  ✓ Conversion drivers (CTA, headlines, pricing)
  ✗ Micro-optimizations (button shades, spacing)
  
We use:
  ✓ Statistical significance (p < 0.05)
  ✓ Minimum sample size (1,000 visitors per variant)
  ✓ 2-week test duration (except urgent CTAs)
  
We win when:
  ✓ Variant beats control by 20%+ (not just 2-3%)
  ✓ Result is repeatable (test again to confirm)
  ✓ Changes are deployed immediately
```

## 6. COPY GUIDELINES FOR DEVS

### Tone of Voice

✅ DO:
- Warm and encouraging
- Specific data (not hype)
- Empowering language (Maîtrise, Progression)
- French tone (Experts certifiés, Parcours)

❌ DON'T:
- Corporate jargon ("leverage", "synergize")
- Hype words ("amazing", "incredible", "game-changing")
- American tone in French copy
- Generic benefits ("powerful", "intuitive")

### Copy Checklist

- [ ] Is it specific? (numbers, not adjectives)
- [ ] Does it address a real objection?
- [ ] Does it use empowering language?
- [ ] Is it scannable? (headlines, bullets)
- [ ] Is it French-appropriate?
- [ ] Does it have a clear CTA?

### Localization (if expanding)

```
France: "Préparez-vous à l'EAF"
Belgium: "Préparez-vous aux examens de français"
Switzerland: "Progressez en français"
Canada: "Réussissez votre cours de français"

Keep tone consistent, adjust exam names only.
```

## 8. CONVERSION RATE TARGETS

### Landing Page (This Document)

```
Visitor → Click Hero CTA: 20% (8-10% actually signup)
Signup → Email Verify: 85%
Verify → Start First Assignment: 30%
Start Assignment → Upgrade Intent: 20%
Upgrade Intent → Conversion: 15-30% of intents = 2-5% of landings

Overall: 8-12% visitor → trial signup
```

### Email Sequences

```
Welcome open: > 35%
Progress email → Premium interest: > 20%
Trial expiring → Upgrade: > 15%
Last chance → Conversion: > 10%
Abandoned → Reactivation: > 5%

Sequence effectiveness: 50-60% of all conversions are email-influenced
```

### Post-Trial Conversion

```
Trial user → Select tier: 40%
Select tier → Enter payment: 95%
Enter payment → Paid subscriber: 100% (if card accepted)

Overall trial-to-paid: 25-30% of trial users
```
